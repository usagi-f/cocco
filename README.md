# 🐾 にくきゅうキャッチ！

[Phaser 3](https://phaser.io/) で作った、かわいい肉球タップゲームだにゃ〜！

▶ **[ここで遊べるにゃ！](https://usagi-f.github.io/cocco/)**

## あそびかた

- 空から猫の肉球が落ちてくるにゃ〜
- 肉球をタップ(クリック)すると「にゃ!」と鳴いて跳ね上がるにゃ！
- 得点になるのは**落ちてきた肉球を拾ったときだけ**にゃ。跳ね上がった直後の連打では加点されないにゃ〜
- 獲得点は**そのとき空中にいる肉球の数**にゃ！たくさん同時にお手玉するほど高得点だにゃ〜！
- 上空では跳ね上げる力が弱くなるから、画面の上に追いやって放置はできないにゃ！
- 違う肉球を連続で拾うとコンボが伸びるにゃ(同じ肉球の拾い直しでリセットにゃ〜)。コンボ10で**にゃんにゃんフィーバー**(6秒間 得点2倍)だにゃ！
- たまに出る**金の肉球**は +10 のボーナスにゃ〜✨
- 時間がたつと肉球はどんどん増えて、落下もだんだん速くなるにゃ！
- ライフは3つにゃ。**3回落としたらゲームオーバー**だにゃ〜…
- ベストスコアはブラウザに保存されるにゃ！

## 動かしかた

外部アセットのない完全な静的サイトにゃ。リポジトリ直下で HTTP サーバーを立てるだけで動くにゃ〜！

```sh
# 例1: Python
python3 -m http.server 8000

# 例2: Node.js
npx serve .
```

ブラウザで <http://localhost:8000> を開いてほしいにゃ！`index.html` をファイルとして直接開いても動くにゃ〜。

## 技術メモ

- **Phaser 3.90.0** を `vendor/phaser.min.js` に同梱してるにゃ(ビルド不要・オフラインでも動くにゃ〜)
- **アート**: 肉球・猫・雲・ハートはぜんぶ Phaser の `Graphics` でコード描画して、テクスチャとして生成してるにゃ！
- **サウンド**: 猫の鳴き声(ピッチグライド+ビブラート)も効果音も、ぜんぶ Web Audio API でリアルタイム合成にゃ〜
- **物理**: Arcade Physics にゃ。画面の左右と上では跳ね返って、下だけすり抜けて落下判定にゃ！
- **レスポンシブ**: `Scale.EXPAND` でアスペクト比を保ったままゲーム世界を広げて、余白なしで常に画面全体に表示するにゃ〜(デザイン基準は480×720にゃ)
- **デプロイ**: ブランチに push すると GitHub Actions が `gh-pages` へ公開してくれるにゃ！
