# 🐾 にくきゅうキャッチ！

[Phaser 3](https://phaser.io/) で作った、かわいい肉球タップゲームです。

## あそびかた

- 空から猫の肉球が落ちてきます
- 肉球をタップ(クリック)すると「にゃ!」と鳴いて少しだけ跳ね上がります
- 地面に落とさないように連続でタップし続けてスコアを稼ぎましょう
- 時間がたつと肉球はどんどん増え、落下もだんだん速くなります
- 一度落ちた肉球は戻りません。**ぜんぶ落としてしまうとゲームオーバー!**
- ベストスコアはブラウザに保存されます

## 動かしかた

外部アセットのない完全な静的サイトです。リポジトリ直下で HTTP サーバーを立てるだけで動きます。

```sh
# 例1: Python
python3 -m http.server 8000

# 例2: Node.js
npx serve .
```

ブラウザで <http://localhost:8000> を開いてください。`index.html` をファイルとして直接開いても動作します。

## 技術メモ

- **Phaser 3.90.0** を `vendor/phaser.min.js` に同梱(ビルド不要・オフライン動作)
- **アート**: 肉球・猫・雲・ハートなどはすべて Phaser の `Graphics` でコード描画し、テクスチャとして生成
- **サウンド**: 猫の鳴き声(ピッチグライド+ビブラート)や効果音はすべて Web Audio API でリアルタイム合成
- **物理**: Arcade Physics。画面の左右と上では跳ね返り、下だけすり抜けて落下判定
- スマホ向けの縦画面レイアウト(480×720、`Scale.FIT` で画面にフィット)

## ファイル構成

```
index.html          エントリーポイント
src/game.js         ゲーム本体(シーン・効果音・テクスチャ生成)
vendor/phaser.min.js Phaser 3.90.0
```
